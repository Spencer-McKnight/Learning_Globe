Welcome to learnthe.world Learn the World! This is a fresh, modern project with the ambitious aim to increase geographical literacy worldwide.

Problem Statement:
People all over the world don't know which country is which, especially when it comes to those lesser-known and unique. Education doesn't fully engage students when teaching such content, so many people fall through the gaps.

Solution Concept:
Create a visually appealing, interactive world map where people can pin their guesses at a country. Then, have their guesses validated in a gamified, real-time manner that adds interactive feedback to guessing streaks, new country discoveries, optional hints, and a robust settings dashboard which allows much of the possibilities to be toggled.

Target Audience:
This application is a free website, as such it should be made with love and quality for the world. This is really a special gift to humanity.

I believe that larger money can primarily be made through deals with educators. Therefore it needs to be understandable enough for potentially very young, with the default mode being quite accessible and legible.

However, there is a secondary audience for the geographic interested person or parents. It could serve as an intelligence game for children that may replace the iPad-driven raising we see prevailant, or be used in high school or university individually to encourage wisdom.

Functional Requirements:

- Utilises a strong source technology for mapping and globes (this will be the key to success with this project)
- Must use a standardised world globe - importantly, the borders should not be represented precisely as to avoid conflict between idealogies.
- Able to switch between flat maps (with different flat map methodologies available in settings), and a 3 dimensional globe.
- Either of the above, should include absolute interaction intuition through multidimensional cursor control.
- Extreme accessibility in mind, either complete mouse or complete keyboard modes or controls available as often as possible. Lesser-abled individuals must be able to use this.

Gamification Element:

- You are free to ideate on how to curate a gamified scoring system, sound effects, great visual effects, UI elements, leaderboard page, etc, that support the gamification of this interaction. This allows learning to provide a dopamine source that contends with modern games.
- Tutorial mode that asks non-invasively whether the user would like a tutorial.

Non-Functional Requirements:

- Mobile-first development; gamification leads to mobile first.
- It should scale to desktop, but the UI need not change to desktop, it can rely on mobile paradigms.
- Favour minimalism without needless content, everything in the UI has a place as to not be too overstimulating.
- Accessibility as a core value.

Best Practices:

- Abstraction of variables: all content displayed anywhere should be captured in constants for future translation efforts.
- Abstraction of styles: colour choices and css reusables, constants should be used to preserve design language easily.

Future Development Intentions (Not yet a constraint):

- Ability to show topographical heights to teach mountains, etc, with a scale that is visible on a zoomed-out world view.
- Dynamic, cached multi-language support.
- Country and a State or Province mode, or All.
- Map pins that evolve the more you get right into shinier, artistic or stylised, caracatures

Other Driving Considerations:

- It should be relatively forgiving, allowing a victory if the selection is within that country at all. Getting closer to the center of the country should allow for the final 10% of score.
- Scores should start off small and quickly scale into the millions during a single run, almost like those cookie-clicker esque scoring systems.
- Different modes are possible with configurable controls.
- Consider a comprehensive technical stack with maps, interactions, performance, ui, etc. We want to leverage what's already been made to make this app better.
