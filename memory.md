# learnthe.world — Decision Log

> Brand (2026-07-20): rebranded from "Learning Globe" to the domain **learnthe.world** (https://learnthe.world). Hero reads "LEARN THE / World"; appName in strings.ts is `learnthe.world`.

## Technical stack (decided 2026-07-19, committed — do not re-litigate)

- **Vite + React 18 + TypeScript (strict)** — fast dev loop, component model for the many UI surfaces (HUD, settings, passport, leaderboard), TS for safety across the geo math.
- **d3-geo + HTML canvas** for all map/globe rendering. Chosen over MapLibre/Globe.gl/three.js because:
  - One projection API covers the 3D globe (orthographic) *and* multiple flat projections (Natural Earth, Equal Earth, Mercator) — switching is a settings toggle, no dual engines.
  - `geoContains` gives point-in-country hit-testing with no tile server, no API key, no network.
  - Canvas 2D easily hits 60fps for 177 generalized country polygons on mobile.
- **Natural Earth 1:110m admin-0 countries** (vendored at `public/data/world.json`, prepared by `scripts/prepare-data.mjs`). Generalized borders deliberately satisfy the "borders should not be represented precisely" requirement. We follow Natural Earth's de-facto standard for what is a country; entities without an ISO code (N. Cyprus, Somaliland) render as land but are excluded from the quiz pool to stay neutral. Antarctica renders but is not quizzed.
- **Capitals** merged at build time from restcountries.com into the same vendored file. No runtime network calls anywhere.
- **WebAudio-synthesized SFX** (no audio assets), **localStorage** persistence (settings, passport, leaderboard, lifetime stats), **@fontsource** bundled fonts (no CDN fonts).
- No state library — React `useReducer` + context is enough.

## Design language

- Palette is the user-supplied "Deep Blue Sea" scheme (see design.md), revised 2026-07-19 into a **tonal depth scale** at the user's request: abyss `#060a18` (space/app bg) < ocean `#102043` < land `#41608a` < light hairline borders `rgba(180,205,230,0.5)`. Verified contrast: land/ocean 2.49:1 (was 1.78:1), coastline stroke/ocean 3.5:1, globe no longer shares the page hex (was 1.00:1). Panels stay Space Indigo `#1c2541`; Tropical Teal `#5bc0be` = interactive, Aquamarine `#6fffe9` = success/streak heat, coral `#ff7a6b` = misses, sand-gold `#ffd97a` = discoveries *and* hint cost. A seeded canvas starfield fills the abyss (disabled in high contrast).
- **On-map text token** (2026-07-20): `--color-text-onmap` (theme.css, aliased to the deriveCaptionInk output) is the sanctioned colour for UI text floating directly over the globe — tagline and explore link use it; the explore link's old bg-glow text-shadow was removed.
- **Well token** (2026-07-20): `--color-well` backs all in-panel fills (inputs, tracks, stat tiles, log/leaderboard rows, stamps). Dark worlds keep `surfaceSunken`; light worlds get `tint(surface, 0.6)` set by applyThemeToDom — darker-than-panel fills on light themes read as disabled.
- Type: **Baloo 2** (chunky, rounded display — legible for young players) + **Nunito** (body/UI). All display text lives in `src/content/strings.ts`; all colors/spacing in CSS custom properties in `src/styles/theme.css`.
- **Signature interaction: sonar ping.** Every pin drop ripples like sonar — aquamarine rings for a correct guess, coral for a miss. The map is dark ocean; feedback is light.

## Game design

- Core loop: prompt shows a country name → player drops a pin → anywhere inside the country counts as correct (forgiving, per spec). Proximity to the country's centroid scales the final 10% of the score.
- Scoring (cookie-clicker curve, per spec): base 1,000 × streak multiplier `2^min(streak,11)` × accuracy (0.90–1.00) × speed bonus (×1.5 under 4s, ×1.25 under 9s) × attempt penalty (½ per retry) × hint penalty (×0.7 each). Perfect runs reach the millions.
- 3 attempts per country (configurable 1–3); misses stamp stylized distance captions under each pin on the map (prior tries stay visible for the turn) plus a thin aquamarine glow ring snapped to an 8-wind compass direction — never an exact bearing. Exhausting attempts reveals the country and resets the streak.
- **Discoveries**: first-ever correct guess of a country stamps it into the persistent Passport (+50,000 bonus, gold fanfare). Collection meta-game drives long-term retention.
- Hints (3 tiers, each ×0.7 score): continent → flag + capital → population (no map giveaway).
- Modes: Quiz (region-filtered: World or per-continent pools) and **Explore** (tap any country, learn its name/flag/capital — no scoring).
- Leaderboard: local top-10 per region. Tutorial: non-invasive first-run offer, 3 steps.

## Accessibility commitments

- Full keyboard play: hold arrows to glide (velocity + coast via InteractionController), +/− zoom, Enter drops the pin at a center crosshair, H for hint. Complete mouse-only play too.
- `aria-live` announcer for prompts/results, visible focus rings, ≥44px touch targets, `prefers-reduced-motion` honored (ripples/confetti become fades), high-contrast toggle.

- 2026-07-20: **The round planner — memory model + multi-vector country selection** (user-requested: "dynamically and automatically select an enjoyable gamified variation of countries"). Replaces the v1 familiarity-weighted picker in `game/selection.ts`; new `game/memory.ts`.
  - *Research base (do not re-litigate the constants without re-reading this).* Three "optimal difficulty" numbers circulate and they answer different questions: Wilson et al. 2019's 85% rule is the optimum for **learning rate per trial**; FSRS/Anki's 0.90 desired retention is a **scheduling threshold** minimising review time per unit retained; Papoušek & Pelánek's adaptive map quiz (slepemapy.cz — the closest published relative of this game) settled on **0.75 realised accuracy** for motivation, and found easy questions win short-term engagement while hard ones win long-term learning. Resolution used here: **0.90 retention governs *when* a known country is due; 0.80 expected success governs *which* unknown country to introduce.** A wrong tap here is cheap (the answer lights up instantly), so this sits on the demanding side of Papoušek's number.
  - *Memory model* (`memory.ts`): FSRS-4.5 — published default weight vector `w0..w16`, power forgetting curve `R(t) = (1 + (19/81)·t/S)^-0.5` (so `S` = days until R hits 0.9). Exponential decay is empirically wrong; real forgetting is heavy-tailed. Deliberately **not** mixed with FSRS-6's curve (`w20 = 0.1542`) — a fitted parameter set is only coherent with its own version. Grades come from the guess journal: reveal/skip → 1, hit with retries or hints → 2, slow clean hit → 3, fast clean hit → 4. Initial difficulty blends the grade with the geography prior (`PRIOR_ANCHOR = 0.4`).
  - *New history signals* (`storage.ts` `GuessRecord`, both optional so old records still load): **`ms`** (prompt→resolution time; hesitation separates grade 3 from 4) and **`miss`** (the isos actually pinned — captured in `evaluateGuess`'s miss branch via the `misfires` ref, flushed in the journal effect).
  - *Five vectors, multiplied into one weight per candidate:* (1) **schedule** — `urgency(R)` peaks exactly at R = 0.9 and floors at 0.6 for long-forgotten, so the best review is the one about to fail; (2) **flow** — Papoušek's tent `P/target` / `(1-P)/(1-target)` raised to `FLOW_SHARPNESS = 2.5`, over `P_est = σ(θ − β + 0.8·logit R)` (ability and memory freshness combined in log-odds); (3) **exploration** — Papoušek's `1/√(1+n)`, which is what stops an adaptive scheduler quietly narrowing to two dozen countries (measured: raised sim coverage 152 → 172 of 174); (4) **confusion** — the impostor a player wrongly pinned gets ×2.2 decayed on a 14-day half-life; (5) **lag** — prompt-count damp plus a 20-minute session damp.
  - *Ability* is Elo/1PL over the whole history, `K(n) = 1/(1 + 0.05n)` (Pelánek's grid-searched values; one online pass matches full MLE at r = 0.97), starting at `NOVICE_ABILITY = -0.6` — a new player is a beginner, not an average. Measured against the **geography prior**, never the FSRS difficulty, which drifts with performance on that very country and would make the yardstick elastic.
  - *Difficulty prior from the map itself* (no hand-maintained table, which would go stale and can't be localised): `0.5·obscurity(log pop) + 0.32·smallness(log area) + 0.18·crowding(mean angular distance to 3 nearest centroids)` → 1..10. Verified by sampling 4,000 cold-start rounds: most likely are US/Russia/China/India/Brazil/Canada/Australia/Mexico; least likely Djibouti/Gambia/Kosovo/Eswatini. Papoušek's caveat holds — real difficulty is population-dependent (a Czech child knows Slovakia), so `player_country_stats` is the eventual path to a locale-segmented prior.
  - *Sequencing* is greedy over interleaving + arc: open on the highest expected success (momentum), ramp challenge, hop continents (Brunmair & Richter 2019: g = 0.42 for interleaving, largest where categories resemble each other — i.e. exactly here), and keep confusion partners ≥3 apart so the contrast teaches instead of giving the answer away. Interleaving is **eased for beginners** (`INTERLEAVE_FULL_AT = 80` prompts) because it costs more than it pays before the learner has a category to discriminate with.
  - *The curio slot:* ~35% of rounds trade their least urgent pick for a delightful outlier. Gated behind `CURIO_MIN_HISTORY = 30` — the first version served *French Southern and Antarctic Lands* to brand-new players at 21%, which is not a delight, it is a wall. Note the literature's warning: keep variable reward in the **presentation** layer; never inject a random easy item for a dopamine hit, it costs real learning.
  - *Verification:* no test framework in this repo, so `scratchpad/sim.ts` + `probe.ts` (bundle with `npx esbuild --bundle --platform=node --alias:d3-geo=node_modules/d3-geo/src/index.js`) run a synthetic learner for 60 rounds. Final: 91% accuracy, 172/174 countries discovered, same-continent back-to-back 5.7% (vs ~19% uniform), median repeat gap 69 prompts, 73/102 impostors rescheduled, ability tracking -0.19 → 1.37 logits.
  - *`RoundPlan.picks` carries a `PickReason`* (`discovery` / `faded` / `review` / `shaky` / `confusion` / `curio`) per country. Nothing renders it yet — it exists so the Results screen can one day say *why* the world chose where it did.

  - *Four heat tiers* (was two): calm accent → `is-hot` ×8 (success, 1.15rem) → `is-blazing` ×64 (reward, 1.3rem, blaze pulse) → **`is-mythic` ×512** (1.45rem, animated prismatic gradient clipped to the glyphs — reward→danger→accent — plus `capsule-surge` box-shadow breathing on the capsule). The score digits climb the same ladder: text→success, success→reward, then the same `score-prism` sweep at mythic. The rising `+N` also grows with heat (1.45rem hot, 1.7rem blazing+).
  - *Motion is layered by property so animations never fight*: `mult-stamp` owns scale/rotate/opacity (slams past the resting tilt to 14° and settles at 8°), `mult-bob` owns translate (idle drift, faster per tier), `mult-blaze` scale-pulses after the stamp ends, `score-prism` owns background-position (to `150%` of a 300% tile = seamless loop). ×1 wears `.is-one`: muted, smaller — a promise, not a prize. - 2026-07-21: **Live /guide 404 fixed + real 404 page** (user-reported: learnthe.world/guide returned Vercel's plain-text NOT_FOUND). Two-part fix:
  - *The cause.* The site is hosted on Vercel with no `vercel.json`, so deep links (`/guide`, `/privacy`) hit filesystem routing and 404'd before the app ever loaded — exactly the SPA-fallback debt the info-pages entry above flagged. Added `vercel.json` with the single rewrite `/(.*) → /index.html`; Vercel serves filesystem matches (hashed assets) first, so nothing else changes. Takes effect on the next deploy.
  - *The consequence.* With every path now rewritten to the bundle, an unknown URL would silently render the game. `Root` in main.tsx now only renders `App` for `/` and shows `NotFoundPage` otherwise, so bad links are named, not absorbed.
  - *NotFoundPage.tsx* — "Uncharted territory". Wears the info-page chrome (eyebrow, display type, theme tokens, pre-paint theme snapshot) but is one centred card: a giant 404 where `IconCompass` plays the zero (7s `nf-wander` needle-searching loop; killed by `prefers-reduced-motion` and `body.reduce-motion`), the lede, the attempted path in a truncating `<code>` chip (16em ellipsis, so garbage URLs can't break layout), then a filled "Back to the world" CTA + ghost pills to /guide and /privacy. Copy in `STR.notFoundPage` (no em dashes per house style); styles in theme.css under "404". Card is `width:100%; max-width:36rem` so the pill row wraps instead of widening the track.
  - Note that a rewrite means unknown paths return HTTP 200 with the 404 view (standard SPA trade-off); fine for us since nothing links to bad paths and robots have nothing to index there.
  - Verified: production build clean; headless Chrome at 500px/1280px, plus a 360px iframe capture (dodges the 500px headless clamp above) confirming wrap/truncation behaviour.
